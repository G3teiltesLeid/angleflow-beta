# Angleflow Beta – Downloads

**Mac:** lade `Angleflow-Beta-<Version>.dmg` · **Windows:** lade `Angleflow-Beta-Setup-<Version>.exe`
Beides unter **Releases** rechts (oder [hier, die neueste Version](https://github.com/G3teiltesLeid/angleflow-beta/releases/latest)).

Die anderen Dateien im Release (`.sha256`, `appcast-mac.xml`, `appcast-windows.xml`) brauchst du nicht: sie sind für die
App, die damit Updates findet und prüft.

Erster Start · Mac: Doppelklick → „Fertig“ → Systemeinstellungen › Datenschutz & Sicherheit › „Trotzdem öffnen“.
Erster Start · Windows: „Der Computer wurde durch Windows geschützt“ → „Weitere Informationen“ → „Trotzdem ausführen“.
Dann den Beta-Schlüssel einfügen, den du bekommen hast. Hilfe › „Pack feedback to send…“ packt deine Notizen als ZIP.

**Mac:** download `Angleflow-Beta-<version>.dmg` · **Windows:** download `Angleflow-Beta-Setup-<version>.exe`
(under **Releases**, or [the newest one here](https://github.com/G3teiltesLeid/angleflow-beta/releases/latest)).
The other files (`.sha256`, `appcast-*.xml`) are for the app's updater – nothing to download.
First start · Mac: double-click → "Done" → System Settings › Privacy & Security › "Open Anyway".
First start · Windows: "Windows protected your PC" → "More info" → "Run anyway". Then paste your beta key.
